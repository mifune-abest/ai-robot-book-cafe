# AI ROBOT BOOK CAFE

子ども食堂のレクリエーション用に、4台のPCで使うローカルWebアプリです。Mac 1台でサーバーを起動し、同じWi-FiのPCから各画面を開きます。

## 4つのアプリとZDR未承認時の代替画面

| PC | 画面 | URL |
|---|---|---|
| ① | おしごとへんしん | `/career` |
| ② | デニムこうさく | `/craft` |
| ③ | りそうをつくろう | `/dream` |
| ④ | きょうのおもいで | `/memory` |
| ⑤ | おしごとカード（①の代替） | `/career-card` |

スタッフ画面は、ホストMacだけで `http://127.0.0.1:4311/host` を開きます。LANへは公開されません。

## 現在の完成範囲

- 子ども向け5画面とホスト画面
- ①の職業質問は全4画面。1番目の回答を最優先の興味として保ち、その後の回答で役割や方法を具体化しながら`gpt-5.5`が質問と4つの選択肢を毎回生成
- 固定一覧を使わない職業提案。生成後に別のGPT処理で実在性を再点検し、実在職業3件を表示（夜職は除外）。③の5回の壁打ち、④の一言分類
- ①のカメラ撮影・撮り直し・印刷画面
- ①の写真は、LAN経由のHTTPではカメラ撮影・ファイル選択とも送信拒否
- ①の完成画像は45分経過後に削除対象となり、サーバー再起動時にも削除
- ⑤は①と同じ職業質問・提案を使い、職業名から汎用人物・服装・背景・小道具が一体になった職業場面を`gpt-image-2`で生成。本人写真は外部AI・Webサーバーへ送らず、ブラウザ内のMediaPipe顔メッシュで顔の内側だけを置き換えて印刷
- ②の実物素材写真登録と、登録素材だけを画像AIへ渡す処理
- ③のジャンル設定・自由入力と、ジャンル・過去の回答を基に`gpt-5.5`が毎回作る5つの質問・4選択肢、5回答後だけの画像生成
- ④の予定人数確認、受付内容の削除、欠席時の人数修正、締切、生成、ホスト確認、手動公開
- ④の確認付き新イベント準備と、ホスト画面でのAI処理状況表示
- ④は全員分の番号付き配置ガイドと一言を`gpt-image-2`へ渡し、ホストが人数と明るさを目視確認してから公開
- 公開画面とホスト専用画面を別ポートに分離
- 入力長制限、危険表現・連絡先の拒否、画像EXIF除去、`no-store`

## AIの構成と安全な既定値

### 会話AI

①・③・④・⑤の会話処理には、Codex app-serverをローカルの`stdio`で起動し、`gpt-5.5`を使います。①〜④の実画像生成も同じCodex app-server経路を使い、Codex組み込みの`gpt-image-2`で生成します。⑤は職業名だけから汎用人物を含む完成済みの職業場面を同じ経路で生成し、本人写真の顔メッシュはブラウザ内のCanvasでその人物の顔へ合成します。

- Codex CLIへのログインとインターネット接続が必要です。
- Codex app-server自体をLANの待受サーバーとして公開しません。LANへ公開するのは、このアプリの子ども用Web画面だけです。
- 別モデルや別のAI基盤へ自動的に切り替えません。ログイン、ネットワーク、利用枠、モデル利用権限のいずれかに問題がある場合は、起動前確認で停止します。
- Codex app-serverは**experimental（試験的機能）**です。仕様変更や提供終了の可能性があるため、イベント前に必ず実機で確認してください。
- 会話文はCodex経由でOpenAIへ送信されます。実名、学校名、住所、電話番号などを入力させないでください。
- 現在の実画像モードは**成人テスト専用**です。①の写真、②の素材画像、③・④の入力文はCodex経由でOpenAIへ送信されます。

### 画像生成

安全な既定値は`IMAGE_PROVIDER=mock`かつ`CAREER_CARD_OUTFIT_PROVIDER=mock`です。この状態では画像生成のための写真・素材・入力文を外部へ送りません。

- ①：撮影写真に職業名を載せた印刷テスト画像
- ②・③：画面遷移を確認するテスト画像
- ④：ローカルで作る人数確認用イラスト
- ⑤：ローカル顔合成の画面遷移を確認する架空成人画像

成人だけで実画像を確認する場合は、`.env`で`IMAGE_PROVIDER=codex`と`ADULT_TEST_MODE=true`を設定します。APIキーは使わず、Codex CLIのログイン状態と一般Codex利用枠を使います。Codex組み込み画像生成は`gpt-image-2`です。

①の代わりに⑤だけで実際の職業場面を生成する場合は、本人写真を外部へ送らない次の設定を使います。`ADULT_TEST_MODE=true`にはしません。

```text
IMAGE_PROVIDER=mock
CAREER_CARD_OUTFIT_PROVIDER=codex
ADULT_TEST_MODE=false
```

⑤のローカル合成は`CAREER_CARD_COMPOSITOR=smart`が既定です。`@mediapipe/tasks-vision` 1.0.1のFace Landmarkerで、本人写真とCAS職業場面の顔が各1人で正面を向いていることを確認します。CASから借りるのは両目の中心・距離・傾きだけとし、本人の目・鼻・口・輪郭の比率を変えない相似変換で478点を配置します。三角形ごとに本人の顔内側を写し、CAS側の低周波の照明・色、顔境界、前髪をPC内でなじませます。CAS側の耳、ヘルメット、首、肩、服、手、小道具、背景は残ります。WASMと顔モデルは同一接続先から配信し、起動時にSHA-256を確認します。モデルがない、改変されている、顔を検出できない場合は処理を停止し、本人写真を外部AIへ送る方式には切り替えません。

実装と未確認範囲は[⑤ローカル顔合成の実装・検証記録](docs/LOCAL_FACE_COMPOSITING_PLAN.md)を参照してください。

画像生成と会話AIは、4台テストのため既定で最大2件を同時処理します。負荷やエラーが増える場合は、`.env`の`IMAGE_CONCURRENCY`と`TEXT_CONCURRENCY`を`1`へ戻します。設定できる範囲は1〜4です。

①の職業質問は全4画面です。1番目の回答を最優先の興味として、その後の回答で好きな役割や方法を具体化しながら`gpt-5.5`が質問と4つの選択肢を毎回生成します。具体的な興味が示された場合、上位2つの職業はその興味が仕事内容へ直接含まれる候補にします。「アイドルになりたい」と明示した場合は、外見ではなく歌・ダンス・演技・トークなどを質問し、候補1を「アイドル」にします。AIが外見に関する質問を返した場合は、安全な活動質問へ置き換えます。

職業名は固定一覧に限定せず、3つの自由な候補から本人が選びます。候補は生成とは別のGPT処理で再点検し、造語・架空の役・一般に夜職と呼ばれる職業は除外します。ただし、公的な職業データベースとの照合ではないため、全ての名称の実在を機械的に保証するものではありません。画像生成時は職業名を内部の安全分類へ分け、確認済みの服装・背景表現だけを使います。本人の顔・見た目の年齢・体格を保ち、印刷物にはAI生成画像であることを表示します。

⑤はZDRが承認されない場合の代替です。4つの興味回答と職業名は会話AIへ、選択した職業名と職業用の視覚ヒントは画像AIへ送信されます。撮影・選択した本人写真はブラウザから送信せず、サーバー保存もしません。画像AIが作った完成済みの職業場面へ、ブラウザ内で本人の顔の内側だけを重ねます。CAS側の髪・頭装具・首・体・背景は維持します。別PCからHTTPで開いた場合も写真ファイル選択は利用できますが、ブラウザのカメラ撮影にはHTTPSが必要です。

③は、選ばれたジャンルとそれまでの質問・回答を基に、`gpt-5.5`が次の質問1つと4つの選択肢を5回すべて毎回作ります。固定質問への自動切替は行わず、AI応答が不正な場合はエラー画面で停止します。

`ADULT_TEST_MODE=true`は、未成年者の利用許可ではありません。未成年者が参加する前に実画像モードを停止してください。未成年者画像の利用条件は、[未成年者画像利用ガイドライン](docs/MINOR_IMAGE_GUIDELINES.md)を参照してください。**保護者同意だけでは実画像生成を有効にできません。**

## 最初の起動

先にCodex CLIのログイン状態を確認します。

```bash
codex login status
```

未ログインの場合だけ、次を実行して画面の案内に従います。

```bash
codex login
```

その後、Macのターミナルで起動します。`npm ci`は初回または依存ライブラリ更新時だけ必要です。

```bash
cd /Users/hina1216/Documents/Codex/2026-07-28/ai-robot-book-cafe-pc-ai/outputs/ai-robot-book-cafe
npm ci
./scripts/start.command
```

通常起動と障害復旧には、`npm start`ではなく`./scripts/start.command`を使います。このスクリプトが`.env`の読込、Codex app-serverのログイン・モデル・実応答確認、証明書検査、ログ保存、Macのスリープ防止をまとめて行います。

起動時に次の2行を確認してください。

```text
Codex app-server: 準備OK (gpt-5.5)
Codex app-server: GPT応答テストOK
画像: Codex app-server / gpt-image-2（外部送信あり）
利用者: 成人テスト専用（未成年者には使用しない）
```

## テスト

`start:test`が新しい一時フォルダを作り、`APP_TEST_MODE=1`で会話・画像とも外部送信しないテストモードを起動します。本番の`data/`は使いません。`start:test`と`check`はCodex接続、ログイン、`gpt-5.5`、`gpt-image-2`の利用可否を確認しないため、実GPTの確認には別途`./scripts/start.command`内のpreflightを使います。

```bash
# ターミナルA
npm run start:test

# ターミナルB
npm run check
```

テストサーバーを停止するには、ターミナルAで`Control + C`を押します。
