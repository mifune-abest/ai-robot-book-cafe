# UI設計

## 共通

```text
対象利用者：小学1〜6年生（必要に応じて会場スタッフが補助）
この画面で完了させる1つの仕事：各PCに割り当てたレクリエーションを1つ完了する
利用前の状態：説明を読まず、初めて画面を見る
完了後の状態：画像を受け取る、または思い出の一言を送信できている
主な利用端末：会場内のPC（1366 × 768を基準）
既存業務の何を置き換えるか：口頭での質問整理、画像生成用プロンプト作成、参加者集計
今回やらないこと：利用者アカウント、予約、SNS共有、決済、成績評価
```

## 設計原則

- 1画面に質問または主要操作を1つだけ表示する。
- 子ども向け画面に管理設定や技術情報を表示しない。
- 選べる内容は大きなボタン、自由入力は短文1つにする。
- 処理中は押せない状態と進み具合を明示する。
- 失敗時は原因コードではなく、スタッフを呼ぶ操作を示す。
- 氏名は収集せず、④だけ重複確認用のニックネームを使う。

## アプリ別の1つの仕事

1. **おしごとへんしん**：4つの興味質問を進み、固定一覧を使わず生成・再点検された実在職業3件から1つを選び、その姿を印刷する。一般に夜職と呼ばれる職業は候補にしない。
2. **デニムこうさく**：用意された素材と好きな雰囲気から完成イメージを見る。
3. **りそうをつくろう**：ジャンルを選び、ジャンルと過去の回答に合わせてAIが毎回作る5つの質問に答え、イラストを見る。
4. **きょうのおもいで**：テーブルとニックネームを選び、一言を送る。
5. **おしごとカード**：ZDR未承認時に①の代わりとして使い、写真を外部へ送らず職業フォトカードを印刷する。

ホスト画面の仕事は、④の受付開始・人数確認・最終画像作成・公開である。

## ①「おしごとへんしん」の4画面

1. 興味に関する質問を1問ずつ表示し、各画面に4つの選択肢を表示する。
2. 質問と4つの選択肢は、1番目の回答を最優先の興味として保ち、その後の回答で役割や方法を具体化しながら`gpt-5.5`が毎回生成する。最初の質問は回答履歴なしで生成する。
3. 4つの興味回答から固定職業リストを使わず候補を生成する。具体的な最優先の興味がある場合、上位2件はその興味が仕事内容へ直接含まれる職業にする。別のGPT処理で実在性と興味の一致を再点検して3件を表示し、一般に夜職と呼ばれる職業は除外する。
4. 「アイドルになりたい」と明示した場合は、外見ではなく歌・ダンス・演技・トーク・練習について質問し、候補1に「アイドル」を表示する。AIが外見に関する質問を返した場合に限り、安全な活動質問へ置き換える。

## ⑤「おしごとカード」

```text
対象利用者：小学1〜6年生と印刷を行うスタッフ
この画面で完了させる1つの仕事：写真を外部へ送らず、職業フォトカードを作って印刷する
利用前の状態：興味や職業が未選択
完了後の状態：職業名と本人写真を使ったカードを印刷できる
主な利用端末：イベント会場のPC
既存業務の何を置き換えるか：ZDR未承認時のみ、①の外部AI職業写真生成を代替
今回やらないこと：本人写真を使った外部AI画像編集、本人写真の外部送信、本人写真・完成カードのサーバー保存
```

1. ①と同じ4問と実在職業3候補を使い、別URLの独立した画面として提供する。
2. 選択した職業名だけを`/api/career-card/outfit`へ送り、Codex app-serverの`gpt-image-2`で汎用人物・服装・背景・小道具が一体になった完成済み職業場面を生成する。本人写真は送らない。
3. 写真の読込、本人写真とCAS画像の1人判定、478点の顔ランドマーク取得、三角形ごとの顔変形、色合わせ、境界ぼかし、完成カードの保持はブラウザメモリ内だけで行う。本人写真を送る`/api/career/generate`は呼ばない。
4. 本人写真から使うのは顔の内側だけとし、CAS側の髪、耳、ヘルメット、首、肩、服、手、小道具、背景を維持する。完成カードには職業名と読みも表示する。
5. 撮影・確認・印刷の画面には「しゃしんは このPCの なかだけ」と表示する。
6. 次の参加者へ切り替えると前の写真とカードを画面から破棄する。印刷はスタッフがブラウザの印刷画面で実行する。
7. 本人写真の顔が0人・複数人・傾きや大きさが基準外の場合は撮り直しで停止する。CAS画像の顔が検出できない、複数人、横向きの場合も停止する。固定楕円や外部AIへ自動的に切り替えない。

## ③「りそうをつくろう」の5質問

1. 設定済みジャンルまたは自由入力のジャンルから開始する。
2. 1〜5問目の質問と4つの選択肢は、ジャンルとそれまでの回答を基に`gpt-5.5`が毎回作る。
3. 2問目以降は直前の回答を一歩具体化し、已に決まった内容を聞き直さない。
4. 各画面にAIの4選択肢と「じぶんで こたえる」を表示する。
5. AI応答が不正な場合は固定質問へ切り替えず、再試行できるエラー画面で停止する。
