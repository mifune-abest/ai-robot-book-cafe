# AI ROBOT BOOK CAFE 未成年者画像利用ガイドライン

最終確認日：2026年7月28日

## 結論

未成年者が参加する運用では、次の安全設定を維持します。

```text
IMAGE_PROVIDER=mock
ADULT_TEST_MODE=false
```

**保護者の同意だけでは、児童写真を外部AIへ送信してよい状態にはなりません。**

OpenAIの未成年者向けAPIガイダンスでは、13歳未満または適用されるデジタル同意年齢未満の子どもの個人データを処理する前に、Zero Data Retention（ZDR）を実装するよう求めています。対象OpenAI組織・プロジェクトでZDRが承認・設定され、使用経路に実際に適用されることを確認できるまでは、児童写真を送信しません。

Codex app-server経路は、現在の実装からZDRの適用状態を確認できません。**児童写真には使用しません。** 現在の`IMAGE_PROVIDER=codex`は成人テスト専用であり、`ADULT_TEST_MODE=true`を児童写真へ流用してはいけません。

この文書は運用上の安全条件を整理したもので、法律相談ではありません。主催者、会場、対象年齢、利用目的、契約、処理国・地域に応じて、個人情報保護の担当者や必要に応じた専門家による個別確認が必要です。

---

## 1. 対象範囲

このガイドラインは、①「おしごとへんしん」で扱う次の工程に適用します。

1. 子どもの撮影
2. MacへのLAN転送
3. 外部画像AIへの送信
4. 職業画像への変換
5. スタッフによる確認
6. 印刷と本人への受渡し
7. ローカルデータ、ログ、印刷待ちデータの削除

②・③の入力文、④の一言、写真に写り込む他人、名札、背景の書類なども個人情報になり得ます。写真だけを確認対象にしてはいけません。

---

## 2. 現在のデータ経路

| 経路 | 送る内容 | 現在の設定・判断 |
|---|---|---|
| Codex app-server / `gpt-5.5` | ①・③の回答、④の一言などのテキスト | 使用。実名、学校名、住所、連絡先を入力させない |
| Codex組み込み画像生成 / `gpt-image-2` | 成人テスト時の①の写真、②の素材、③・④の画像指示 | 成人テストだけで使用。児童写真には使用しない |
| ローカルWebアプリ | 撮影写真、生成画像、④の受付情報、素材写真 | Mac内で処理・保存。保存先と削除時期を運営で管理する |

Codex app-serverはローカルの`stdio`でアプリと通信しますが、回答生成にはインターネット経由でOpenAIを利用します。「ローカルの`stdio`」は「データがMacの外へ出ない」という意味ではありません。

---

## 3. 実画像生成を有効にする前の必須条件

次の項目が1つでも未確認の場合、`IMAGE_PROVIDER=mock`と`ADULT_TEST_MODE=false`を維持します。

### 3-1. 目的と必要最小限のデータ

- [ ] 利用目的を「職業になりきった画像を作り、その場で本人へ1枚印刷して渡す」など具体的に決めた
- [ ] 写真を別用途の広報、SNS、教材、モデル改善へ流用しないと決めた
- [ ] 実名、学校名、住所、電話番号、メールアドレスを撮影・入力・送信しない
- [ ] 背景に他の子ども、名札、書類、位置情報が写り込まない撮影場所を用意した
- [ ] 送信前のEXIF除去と画像縮小を実機で確認した

目的を後から追加する場合は、元の説明や同意を流用せず、改めて確認します。

### 3-2. 保護者と子どもへの説明

- [ ] 撮影目的、外部AIへの送信、委託先、処理国・地域、保存・削除、印刷、事故時の連絡先を保護者へ事前に説明した
- [ ] 保護者の同意を、対象の子ども・利用目的・実施日が分かる形で記録した
- [ ] 子ども本人にも「何を撮り、何を作り、どこへ送るか」を年齢に合う言葉で説明した
- [ ] 子どもが嫌がる、迷う、途中でやめたいと言う場合は撮影・送信を中止する

個人情報保護委員会は、本人が同意について判断できる能力を個別に判断し、一般に12～15歳以下の子どもについては法定代理人等から同意を得る必要があると説明しています。ただし、保護者同意は、ZDR、国外移転、委託先管理、HTTPS、削除、スタッフ確認などの代わりにはなりません。

### 3-3. 13歳未満とZDR

- [ ] 参加者の年齢範囲を確認した
- [ ] 13歳未満を含む場合、児童写真を処理する**前に**対象OpenAI組織・プロジェクトでZDRを実装した
- [ ] ZDRがOpenAIによる事前承認を要する契約・設定であることを理解し、管理画面表示や契約資料で確認した
- [ ] 使用する実際の送信経路、モデル、対象組織・プロジェクトが、利用日時点でZDR適用可能かつ適用済みであることを確認した
- [ ] ZDRを確認できないCodex app-server経路を児童写真に使わないことを技術担当者が確認した

OpenAIのデータ管理資料では、ZDRは対象となる組織が事前承認を受けて設定する仕組みです。資料上で特定のエンドポイントや`gpt-image-2`がZDR対応可能と記載されていても、モデル名を設定しただけでは個別プロジェクトやCodex経路への適用を証明できません。

### 3-4. 委託先と国外での取扱い

- [ ] OpenAIとの契約主体、利用する組織・プロジェクト、再委託先一覧を確認した
- [ ] データを処理・保存する国や地域、適用するデータレジデンシー設定を確認した
- [ ] 国外移転を同意に基づいて行う場合に必要な、国名、当該国の個人情報保護制度、受領者の保護措置に関する情報提供を確認した
- [ ] 委託先の安全管理、事故通知、削除、契約終了時の扱いを確認した

処理国・地域を推測で「国内」「米国」などと決めません。利用する契約と設定に基づいて確認します。

### 3-5. 保存と削除

- [ ] 元写真、生成画像、失敗画像、ログ、ブラウザキャッシュ、印刷待ちデータごとに保存場所を確認した
- [ ] 削除する時刻、実施者、確認者を決めた
- [ ] OpenAI側の保持条件を、ZDR設定と使用エンドポイントを含めて確認した
- [ ] イベント後のローカル削除を確認する手順を決めた
- [ ] 無断でクラウドストレージ、チャット、メールへ複製しない

このアプリでは①の完成画像が45分経過後に削除対象となり、サーバー再起動時にも削除されます。ただし、元写真、他画面の生成物、OSの印刷スプール、ログを含む全データの自動削除を保証するものではありません。

### 3-6. HTTPSと端末管理

- [ ] 4台すべてで、証明書警告のないHTTPS接続を確認した
- [ ] HTTPではカメラ撮影と写真ファイル選択が拒否されることを確認した
- [ ] 証明書の対象IP、期限、秘密鍵の管理責任者を確認した
- [ ] 子どもだけでホストMacやスタッフ画面を操作できない配置にした

証明書警告を無視する、ブラウザの安全機能を無効にする、HTTPで写真を送る、といった回避運用は禁止します。

### 3-7. スタッフ確認と出力ルール

- [ ] 生成画像を印刷前にスタッフが1件ずつ確認する
- [ ] 顔、年齢、体格が本人から不自然に変わっていないことを確認する
- [ ] 性的表現、成人化、美化、痩身、差別的表現、危険な道具、別人化がないことを確認する
- [ ] 本人の職業に合わせた服装と背景以外が不必要に変わっていないことを確認する
- [ ] 他人の顔や個人情報が含まれないことを確認する
- [ ] 印刷物に「AIでつくった未来のわたし」と表示されていることを確認する
- [ ] 不適切な画像は印刷・公開せず、削除して責任者へ報告する

自動生成から無人印刷へ直結させません。SNS、Webサイト、掲示物への公開は今回の同意範囲に含めず、別の目的・同意・確認が必要です。

### 3-8. 撤回と写真なしの代替

- [ ] 撮影前、送信前、生成後、印刷前の各段階で、子どもまたは保護者が中止・撤回を申し出る方法を決めた
- [ ] 撤回時に、未処理データ、ローカル画像、印刷待ちデータを削除する担当者を決めた
- [ ] 既に本人へ渡した印刷物や外部処理済みデータについて、対応できる範囲と限界を事前に説明した
- [ ] 写真を一切撮らない参加方法を用意し、不参加扱いや不利益にしない

写真なしの代替例は、子どもが選んだ職業名と、人物写真を使わないロボット・道具・仕事場のイラストを印刷する方法です。**現在のアプリで、この代替経路の操作確認は未実施です。** 当日までに用意できない場合、写真利用を拒否した子どもへ撮影を促してはいけません。

## 4. ①の画像変換ルール

実画像生成が正式に承認された後も、変換範囲は次に限定します。

### 保つもの

- 本人と分かる顔
- 実年齢
- 自然な体格と身体比率
- 肌の色、髪型、本人らしい表情

### 変えてよいもの

- 選ばれた職業に合う服装
- 明るく安全な職場の背景

### 変えてはいけないもの

- 成人に見せる変更
- 顔や体型の美化、痩身、筋肉の誇張
- 性的な服装、ポーズ、表現
- 肌の色、身体的特徴、性別表現の一方的な変更
- 危険行為、違法行為、差別的・侮辱的な表現

出力はあくまでAI生成の将来イメージです。適性検査、進路保証、本人の能力評価として扱いません。

## 5. 中止条件

次のいずれかが発生した場合、その場で写真の撮影・送信・印刷を停止します。

- CodexまたはOpenAIのログイン、利用枠、ネットワーク、サービス状態を確認できない
- ZDRの承認・適用状態を確認できない
- API、モデル、データ保持条件が事前確認時から変わった
- HTTPS証明書警告が出る、または固定IPが証明書と一致しない
- 子どもまたは保護者が拒否・撤回した
- 同意対象者と撮影対象者を対応付けられない
- 画面や写真に他の子ども、名札、連絡先などが写り込んだ
- スタッフによる印刷前確認を行えない
- 削除責任者または事故時連絡先が不在

別モデル、別サービス、個人アカウント、HTTP、私物スマートフォンへの撮影で回避しません。
